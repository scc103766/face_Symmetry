# M4：视频动态不对称优化方案

> 创建日期：2026-06-24
> 目标：利用视频帧序列提取动态不对称特征，提升不对称性检测的 Recall 和 Specificity

---

## 1. 背景

当前规则62 基于静态图片的 21 个对称性特征，Precision 0.78 / Recall 0.58 / Specificity 0.72。

核心局限：**只看静态，不看动态**。脑卒中/面瘫的核心病理特征是在动作过程中暴露的不对称——静态可能代偿，但动态时患侧无力，不对称急剧放大。

## 2. 数据

| 数据集 | 患者数 | 视频数 | 标签 |
|--------|:---:|:---:|------|
| stroke_media | 518 | 515 | 是否患病 |
| stroke_warning | 612 | 611 | 风险等级 |

视频内容：患者执行面部动作（正面→微笑示齿→眼球右看等）的完整录制。

## 3. 技术路线

```
视频 → 逐帧 MediaPipe 478点 → 逐帧规则62 21特征 → 时间序列
                                                      ↓
                                          8类动态特征（幅度/波动/恶化/速度/持续/对称/协调/频率）
                                                      ↓
                                          患者级特征 + subject-level split
                                                      ↓
                                          浅模型 → 与规则62融合
```
