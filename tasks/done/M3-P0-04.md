## 📝 任务描述

在现有口唇几何特征基础上，增加**牙齿-嘴唇颜色差异**作为第四类信号，提升露齿检测的召回率（当前 69.7%）和准确率（非口部动作误判 ~5-8%）。

核心思路：当牙齿露出时，口腔内部区域会出现明亮的低饱和度像素（牙齿），与红色高饱和度像素（嘴唇/牙龈）混合。通过 HSV 色差量化这个混合程度。

## ✅ 子任务 1：实现口腔内部颜色分析函数

### 1A：从 478 关键点提取内唇多边形

MediaPipe 的 `REGION_EDGES["lips"]` 包含外唇和内唇两圈轮廓。需要分离出内唇点：

```python
# 内唇关键点索引（从 REGION_EDGES["lips"] 中识别）
# 内唇上弧：78, 191, 80, 81, 82, 13, 312, 311, 310, 415, 308
# 内唇下弧：78, 95, 88, 178, 87, 14, 317, 402, 318, 324, 308
INNER_LIP_INDICES = [78, 191, 80, 81, 82, 13, 312, 311, 310, 415, 308, 324, 318, 402, 317, 14, 87, 178, 88, 95]
```

### 1B：从图片裁剪口腔内部 ROI

接收图片路径 + landmarks，裁剪内唇多边形区域：

```python
def _crop_mouth_interior(
    image_path: str,
    raw_landmarks: list[dict],
    padding: int = 2,
) -> np.ndarray | None:
```

步骤：
1. 用 OpenCV 读取图片：`cv2.imread(image_path)`
2. 获取图片尺寸：`h, w = img.shape[:2]`
3. 将内唇关键点的归一化坐标 (x, y) 转为像素坐标：`px = int(x * w)`, `py = int(y * h)`
4. 构建多边形 mask（`cv2.fillPoly`），只保留口腔内部像素
5. 返回 mask 裁剪后的像素数组（BGR→HSV）
6. 如果口腔区域面积太小（< 20 像素），返回 None（嘴巴基本闭合，无需色差分析）

### 1C：计算牙齿颜色分数

```python
def _teeth_color_score(
    mouth_pixels_hsv: np.ndarray,
) -> dict:
```

对 HSV 图像的口腔内部像素做像素级分类：

```python
# HSV 范围（OpenCV：H 0-180, S 0-255, V 0-255）
TEETH_S_THRESHOLD = 40    # 饱和度的 40/255 ≈ 0.16，牙齿低饱和
TEETH_V_THRESHOLD = 150   # 明度的 150/255 ≈ 0.59，牙齿高亮
DARK_V_THRESHOLD = 60     # 明度的 60/255 ≈ 0.24，暗区
LIP_S_THRESHOLD = 65      # 饱和度的 65/255 ≈ 0.25，唇组织

h, s, v = cv2.split(mouth_pixels_hsv)
total = s.size

teeth_mask = (s < TEETH_S_THRESHOLD) & (v > TEETH_V_THRESHOLD)
dark_mask = v < DARK_V_THRESHOLD
lip_mask = s > LIP_S_THRESHOLD

teeth_ratio = teeth_mask.sum() / total
dark_ratio = dark_mask.sum() / total
lip_ratio = lip_mask.sum() / total

# 综合牙齿颜色分：
#   牙齿像素比例高 + 暗区不多（排除张嘴无牙）→ 高分
#   唇组织比例高但牙齿少 → 低分（闭嘴或张嘴无牙）
teeth_color_score = teeth_ratio * (1.0 - dark_ratio)
```

返回 dict：
```python
{
    "teeth_ratio": float,        # 牙齿色像素比例
    "dark_ratio": float,         # 暗区像素比例
    "lip_ratio": float,          # 唇色像素比例
    "mouth_pixel_count": int,    # 口腔内部总像素数
    "teeth_color_score": float,  # 综合分数 0-1
}
```

### 2B：颜色融合逻辑

在现有几何判断结果的基础上，增加色差信号作为补充/纠正：

```python
# --- 颜色分析（如果提供了 image_path）---
color_features = None
if image_path is not None:
    raw_landmarks = detection.get("raw_landmarks") or []
    color_features = _analyze_mouth_color(image_path, raw_landmarks)

# --- 融合判决 ---
if color_features is not None and color_features["mouth_pixel_count"] >= 20:
    teeth_color_score = color_features["teeth_color_score"]
    # 颜色信号阈值
    TEETH_COLOR_THRESHOLD = 0.15  # 牙齿像素占比 > 15% 才认为有牙齿
    
    if not detected and teeth_color_score > TEETH_COLOR_THRESHOLD * 1.5:
        # 情况 1：几何未检出但颜色强烈 → 挽救漏检（微微露齿场景）
        detected = True
        mouth_state = "teeth_visible"
        tie_break_used = True
    elif detected and teeth_color_score < TEETH_COLOR_THRESHOLD * 0.5:
        # 情况 2：几何检出但颜色不支持 → 可能是张嘴无牙
        # 只在几何刚好在边界时撤销（不在边界时保持几何判断）
        if not (
            lip_gap > TEETH_LIP_GAP_CLEAR_THRESHOLD
            and mouth_stretch > TEETH_MOUTH_STRETCH_CLEAR_THRESHOLD
        ):
            detected = False
            mouth_state = "mouth_open_no_teeth"
```

设计原则：
- **颜色作为独立信号**：不绑定到几何阈值，独立计算
- **颜色不单独触发**：只在几何判断模棱两可时辅助
- **几何明确时颜色不干扰**：lip_gap 远超阈值时不需要颜色确认

## ✅ 子任务 4：新增 `_analyze_mouth_color()` 主函数

整合子任务 1 的三个步骤：

```python
def _analyze_mouth_color(
    image_path: str,
    raw_landmarks: list[dict],
) -> dict | None:
    """
    分析口腔内部区域的颜色特征。

    返回：
        dict with teeth_ratio, dark_ratio, lip_ratio, mouth_pixel_count, teeth_color_score
        None 如果口腔区域面积太小或无法提取
    """
    import cv2
    import numpy as np
    
    # 1. 读取图片
    img = cv2.imread(image_path)
    if img is None:
        return None
    
    # 2. 提取内唇多边形并转为像素坐标
    h, w = img.shape[:2]
    inner_points = []
    for idx in INNER_LIP_INDICES:
        if idx < len(raw_landmarks):
            pt = raw_landmarks[idx]
            inner_points.append((int(pt["x"] * w), int(pt["y"] * h)))
    
    if len(inner_points) < 4:
        return None
    
    # 3. 构建 mask 并裁剪
    mask = np.zeros((h, w), dtype=np.uint8)
    cv2.fillPoly(mask, [np.array(inner_points, dtype=np.int32)], 255)
    
    # 4. 提取口腔内部像素
    mouth_pixels = img[mask == 255]
    if len(mouth_pixels) < 20:
        return None
    
    # 5. 转 HSV
    mouth_bgr = mouth_pixels.reshape(-1, 1, 3)
    mouth_hsv = cv2.cvtColor(mouth_bgr, cv2.COLOR_BGR2HSV)
    h_ch, s_ch, v_ch = cv2.split(mouth_hsv)
    s_flat = s_ch.flatten().astype(np.float32)
    v_flat = v_ch.flatten().astype(np.float32)
    
    total = len(s_flat)
    
    # 6. 像素分类
    teeth_mask = (s_flat < TEETH_S_THRESHOLD) & (v_flat > TEETH_V_THRESHOLD)
    dark_mask = v_flat < DARK_V_THRESHOLD
    lip_mask = s_flat > LIP_S_THRESHOLD
    
    teeth_ratio = float(np.sum(teeth_mask) / total)
    dark_ratio = float(np.sum(dark_mask) / total)
    lip_ratio = float(np.sum(lip_mask) / total)
    
    teeth_color_score = teeth_ratio * (1.0 - dark_ratio)
    
    return {
        "teeth_ratio": round(teeth_ratio, 4),
        "dark_ratio": round(dark_ratio, 4),
        "lip_ratio": round(lip_ratio, 4),
        "mouth_pixel_count": total,
        "teeth_color_score": round(teeth_color_score, 4),
    }
```
