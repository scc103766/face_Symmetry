### 📖 技术教学：为什么用关键点几何替代 blendshape

blendshape 是 MediaPipe 从 2D 图像回归出的 52 维面部动作分数，受光照、角度、遮挡影响大。关键点坐标是 MediaPipe 的直接输出层，精度更高。

以露齿为例：
- blendshape `jawOpen=0.04`：表示"嘴张开 4%"，但 4% 是多宽？依赖训练数据分布
- 关键点 `lip_gap = dist(13, 14) / dist(33, 263) = 0.08`：直接表示唇间距是眼间距的 8%，物理含义明确

同样，侧脸判断用轮廓几何比用鼻部 yaw 更鲁棒——鼻部深度 z 值在极端角度不可靠，但 2D 轮廓宽度在所有角度都单调递减。

## ✅ 子任务 1：侧视检测（纯 478 点几何）

### 特征设计

基于 `feature_extractor.py` 中已有的 `REGION_EDGES["face_oval"]`（36 个面部轮廓点），构建三个几何特征：

**特征 A：轮廓宽度比 `oval_width_ratio`**

```python
# 取 face_oval 中所有唯一点的 x 坐标范围
oval_indices = sorted(set(idx for edge in REGION_EDGES["face_oval"] for idx in edge))
oval_points = [raw_landmarks[i] for i in oval_indices if i < len(raw_landmarks)]
xs = [p["x"] for p in oval_points]
ys = [p["y"] for p in oval_points]
face_w = max(xs) - min(xs)
face_h = max(ys) - min(ys)
oval_width_ratio = face_w / max(face_h, 1e-9)
```

正脸 ≈ 0.65~0.85，侧脸 60°+ 时 < 0.50。

**特征 B：眼区宽度比 `eye_width_ratio`**

```python
# 左右眼外角水平距离 / 脸高
eye_w = abs(landmarks["right_eye_outer"]["x"] - landmarks["left_eye_outer"]["x"])
eye_width_ratio = eye_w / face_h
```

正脸 ≈ 0.25~0.35，侧脸 < 0.15。

**特征 C：鼻翼可见比 `nostril_visibility_ratio`**

```python
# 左右鼻翼 x 跨度 / 脸宽
nostril_w = abs(landmarks["left_nostril"]["x"] - landmarks["right_nostril"]["x"])
nostril_ratio = nostril_w / face_w
```

正脸 ≈ 0.12~0.18，侧脸 >60° 时一侧鼻翼被遮挡，ratio < 0.06。

### 融合判决

```python
# 取最保守的信号（三个中最小值触发）
side_score = min(oval_width_ratio / 0.50, eye_width_ratio / 0.15, nostril_ratio / 0.06)

if side_score < 1.0:
    detected = True
    level = "extreme" if side_score < 0.4 else "moderate" if side_score < 0.7 else "slight"
```

原理：取最保守（最小）的信号，避免单一信号误判。只有三个信号一致指向侧脸时才判 detected。

## ✅ 子任务 2：露齿检测（口唇关键点几何 + blendshape 辅助）

### 特征设计

使用 478 点中的口唇区域关键点，归一化基准为眼间距：

```python
scale = dist(landmarks["left_eye_outer"], landmarks["right_eye_outer"])

```

**特征 A：唇间距 `lip_gap`**

```python
lip_gap = dist(landmarks["upper_lip_center"], landmarks["lower_lip_center"]) / scale
```

闭嘴 ≈ 0.02~0.06，露齿 ≈ 0.08~0.25。

**特征 B：口角横拉 `mouth_stretch`**

```python

```

闭嘴 ≈ 0.80~1.05，露齿时嘴角拉开 ≈ 1.05~1.35。

**特征 C：内唇面积比 `lip_area_ratio`**（用于区分张嘴 vs 露齿）

使用 `REGION_EDGES["lips"]` 的内唇轮廓点（78,95,88...到 308,415，内圈），计算凸包面积：

```python
lip_indices = sorted(set(idx for edge in REGION_EDGES["lips"] for idx in edge))
# 通过 y 坐标区分内唇（y 偏中间）和外唇（y 偏上下）
# 取 y 坐标在 25%~75% 分位之间的点为内唇，计算其凸包面积
lip_points = [(raw_landmarks[i]["x"], raw_landmarks[i]["y"]) for i in lip_indices]
inner_lip_area = convex_hull_area(inner_points) / (scale * scale)
```

闭嘴时内唇面积 ≈ 0.01~0.03，露齿时牙齿撑开内唇 ≈ 0.04~0.15。

### 融合判决

```python
if lip_gap > 0.12 and mouth_stretch > 1.05:
    # 明确露齿：嘴张大 + 嘴角拉开
    detected = True
    mouth_state = "teeth_visible"
elif lip_gap > 0.08 and mouth_stretch > 0.95 and lip_area > 0.04:
    # 内唇被撑开 + 嘴有一定开度 → 露齿
    detected = True
    mouth_state = "teeth_visible"
elif lip_gap > 0.06:
    # 张嘴但未露齿
    detected = False
    mouth_state = "mouth_open_no_teeth"
else:
    detected = False
    mouth_state = "mouth_closed"

confidence = clamp((lip_gap / 0.12 + mouth_stretch / 1.05) / 2)
```

## ✅ 子任务 4：convex_hull_area 实现

```python
def _convex_hull_area(points: list[tuple[float, float]]) -> float:
    """Monotone chain convex hull area."""
    if len(points) < 3:
        return 0.0
    points = sorted(set(points))
    if len(points) < 3:
        return 0.0
    
    def cross(o, a, b):
        return (a[0] - o[0]) * (b[1] - o[1]) - (a[1] - o[1]) * (b[0] - o[0])
    
    lower = []
    for p in points:
        while len(lower) >= 2 and cross(lower[-2], lower[-1], p) <= 0:
            lower.pop()
        lower.append(p)
    
    upper = []
    for p in reversed(points):
        while len(upper) >= 2 and cross(upper[-2], upper[-1], p) <= 0:
            upper.pop()
        upper.append(p)
    
    hull = lower[:-1] + upper[:-1]
    area = 0.0
    for i in range(len(hull)):
        j = (i + 1) % len(hull)
        area += hull[i][0] * hull[j][1]
        area -= hull[j][0] * hull[i][1]
    return abs(area) / 2.0
```
