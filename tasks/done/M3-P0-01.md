### 📝 任务描述

在 `rule62.py` 的 `evaluate_rule62()` 函数中做两个优化：

1. **软评分**：用连续 `evidence_score` 替代二值 `triggered` 贡献
2. **姿态校准**：当受试者图片存在大角度侧脸时，对几何特征打折

---

### 📖 技术教学

#### 为什么做软评分

当前逻辑：
```python
triggered = value >= threshold           # 二值
contribution = weight if triggered else 0  # 0或全量
score += contribution
```

问题：阈值 0.011664 和 0.011665 差 0.000001，但前者贡献 0、后者贡献完整权重。这在统计上不合理。

`evidence_score` 已经计算好了（line 138）：
```python
evidence_ratio = value / threshold       # 连续比例
evidence_score = weight * min(ratio, 2.0)  # 连续贡献，上限2x
```

改用 `evidence_score` 后，特征值越大贡献越大，阈值附近平滑过渡。

#### 为什么做姿态校准

当人脸偏转（yaw > 15°）时，远离镜头的半边脸的 landmarks 在 2D 投影上会被压缩。例如右转 30° 时，右侧眼睛的表观宽度变小，计算出的 `eye_aperture_asym` 会天然偏高——这是透视效应，不是病理不对称。

对策：检测到大幅 yaw 时，对该图片的几何特征贡献打折。

#### 修改 1：软评分

在 `evaluate_rule62()` 中（当前约 line 115-218），修改评分逻辑：

**当前代码**（line 134-144）：
```python
triggered = value is not None and value >= feature.threshold
contribution = feature.feature_weight if triggered else 0.0
medical_priority_contribution = contribution * feature.medical_priority_score
evidence_ratio = None if value is None else value / max(feature.threshold, 1e-12)
evidence_score = 0.0 if evidence_ratio is None else feature.feature_weight * min(max(evidence_ratio, 0.0), 2.0)
medical_priority_evidence_score = evidence_score * feature.medical_priority_score
if value is not None:
    scored_weight += feature.feature_weight
if triggered:
    score += contribution
    triggered_weight += feature.feature_weight
```

**改为**：
```python
triggered = value is not None and value >= feature.threshold
contribution = feature.feature_weight if triggered else 0.0   # 保留用于 attribution
evidence_ratio = None if value is None else value / max(feature.threshold, 1e-12)
evidence_score = 0.0 if evidence_ratio is None else feature.feature_weight * min(max(evidence_ratio, 0.0), 2.0)
medical_priority_evidence_score = evidence_score * feature.medical_priority_score
if value is not None:
    scored_weight += feature.feature_weight
# ── 软评分核心改动：用 evidence_score 替代二值 contribution ──
score += medical_priority_evidence_score
triggered_weight += feature.feature_weight if triggered else 0.0
```

**说明**：
- `score` 现在累加 `medical_priority_evidence_score`（已含 medical_priority 乘数+连续比例+2x封顶）
- `triggered` 和 `contribution` 保留不动（用于 attribution 报告中的 `triggered` 标记和 `weighted_contribution` 字段）
- `triggered_weight` 仍然只在真正触发时累加（报告用）

**阈值适配**：因为分数值域变了，需要在 `build_report()` 或 `evaluate_rule62()` 中调整判决：
- 旧的 `score_threshold`（当前 0.549）是针对二值评分标定的
- 改为软评分后，分数整体会降低（因为不再按"全或无"给分）
- 用 scale_factor 适配：`adjusted_threshold = config.score_threshold * SCORE_SCALE_FACTOR`
- 定义模块级常量 `SCORE_SCALE_FACTOR = 0.65`（经验值：evidence_score 均值约为二值 contribution 的 0.65 倍）
- 判决行改为：`predicted = bool(detected_rows) and score >= adjusted_threshold`

#### 修改 2：姿态校准

在 `evaluate_rule62()` 中，在计算每个特征的 value 之前，对几何特征做 yaw 折扣。

**新增辅助函数**：
```python
def _yaw_discount(detected_rows: list[Mapping[str, Any]]) -> float:
    """计算姿态折扣因子。avg_abs_yaw > 15° 时开始打折，最大折到 0.5。"""
    # 从所有已检测图片中收集 yaw
    # yaw 来自 features 中的 pose_yaw_abs_deg（由 feature_extractor 生成）
    yaw_values = []
    for row in detected_rows:
        features = row.get("features")
        if not isinstance(features, Mapping):
            continue
        yaw = to_float(features.get("pose_yaw_abs_deg"))
        if yaw is not None:
            yaw_values.append(yaw)
    if not yaw_values:
        return 1.0
    avg_yaw = sum(yaw_values) / len(yaw_values)
    if avg_yaw <= 15.0:
        return 1.0
    # 线性折扣：15°→1.0，45°→0.5
    discount = max(0.5, 1.0 - (avg_yaw - 15.0) / 60.0)
    return discount
```

**在 evaluate_rule62 中应用**：
在主循环之前计算一次：
```python
yaw_discount = _yaw_discount(detected_rows)
```

在每次计算 evidence_score 后，对几何类特征应用折扣。

**几何类特征判定规则**：特征名以 `raw_` 开头且不以 `bs` 开头的（raw landmark 派生的几何特征），或特征名包含 `region` 的（区域几何特征）。

```python
# 在 evidence_score 计算之后、score 累加之前：
_GEOMETRY_FEATURE_PREFIXES = ("raw_",)
_GEOMETRY_FEATURE_KEYWORDS = ("region",)
is_geometry = (
    any(feature.feature_name.startswith(pfx) for pfx in _GEOMETRY_FEATURE_PREFIXES)
    or any(kw in feature.feature_name for kw in _GEOMETRY_FEATURE_KEYWORDS)
)
if is_geometry and yaw_discount < 1.0:
    evidence_score *= yaw_discount
    medical_priority_evidence_score *= yaw_discount
```

**姿势信息获取**：如果 `detected_rows` 中的 features 没有 `pose_yaw_abs_deg`（当前 feature_extractor 的输出），需要确认这个字段是否存在。检查 `feature_extractor.py:242-249`——`matrix_features()` 确实生成了 `pose_yaw_abs_deg`。但 `raw_landmark_features` 不生成 pose 特征。pose 特征来自 `matrix_features()`，而它依赖 `detection["pose"]`。

需在 `evaluate_rule62()` 中增加一个 fallback：如果 `pose_yaw_abs_deg` 不在 features 中，从 `detected_rows` 逐行查找 `pose`。但由于 evaluate_rule62 只接收 features dict，没有原始 detection……

**简化为**：直接在 features 中找 `pose_yaw_abs_deg`。如果不存在（旧数据可能没有），yaw_discount 返回 1.0（不打折）。这是安全的 fallback。
