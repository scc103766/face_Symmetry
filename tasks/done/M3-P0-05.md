### 1A：新增 `_teeth_edge_features()` 函数

在 `_crop_mouth_interior()` 返回的 BGR 图像上做分析（与色差分析共用同一 ROI 裁剪结果）：

```python
def _teeth_edge_features(
    mouth_crop_bgr: np.ndarray,    # _crop_mouth_interior 返回的 HSV 之前的 BGR

) -> dict:
```

**特征 A：牙齿连通域宽度 `max_tooth_region_width`**

```python
# 1. 获取牙齿像素 mask（复用已有的 HSV 阈值）
teeth_mask = (s < TEETH_S_THRESHOLD) & (v > TEETH_V_THRESHOLD)

# 2. 连通域分析
num_labels, labels, stats, _ = cv2.connectedComponentsWithStats(
    teeth_mask.astype(np.uint8), connectivity=8
)
# stats[i] = [x, y, w, h, area] for label i（i=0 是背景）

# 3. 取最大非背景连通域的宽度（归一化到 mouth ROI 宽度）
if num_labels > 1:
    areas = stats[1:, cv2.CC_STAT_AREA]
    widths = stats[1:, cv2.CC_STAT_WIDTH]
    max_idx = np.argmax(areas)
    max_width = widths[max_idx]
    max_width_norm = max_width / mouth_roi_width  # 归一化
else:
    max_width_norm = 0.0
```

**特征 B：连通域数量 `tooth_region_count`**

```python
# 只统计面积 >= 最小阈值的连通域（过滤噪声点）
MIN_REGION_AREA = 5  # 像素
significant_regions = sum(1 for a in areas if a >= MIN_REGION_AREA)
```

**特征 C：水平边缘梯度 `edge_gradient_max`**

```python
# 在口腔 ROI 的灰度图上计算水平 Sobel 梯度
gray = cv2.cvtColor(mouth_crop_bgr, cv2.COLOR_BGR2GRAY)
grad_x = cv2.Sobel(gray, cv2.CV_64F, 1, 0, ksize=3)
# 只统计口腔 mask 内的梯度
grad_masked = np.abs(grad_x)[teeth_mask > 0] if teeth_mask.sum() > 0 else np.abs(grad_x)
edge_gradient_max = float(np.max(grad_masked)) / 255.0  # 归一化到 [0,1]
```

返回 dict：
```python
{
    "max_tooth_region_width": float,    # 最大牙齿连通域宽度（归一化，0-1）
    "tooth_region_count": int,          # 显著连通域数量
    "edge_gradient_max": float,         # 最大水平边缘梯度（归一化，0-1）
    "tooth_edge_score": float,          # 综合分数（见下文）
}
```

### 1B：综合边缘分数

```python
# 真牙齿特征：宽区域（>0.3）+ 少区域（1-2）+ 高梯度（>0.15）
width_ok = 1.0 if max_width_norm > 0.30 else max_width_norm / 0.30
count_ok = 1.0 if region_count <= 2 else max(0.0, 1.0 - (region_count - 2) * 0.3)
grad_ok = 1.0 if edge_gradient_max > 0.15 else edge_gradient_max / 0.15

tooth_edge_score = (width_ok + count_ok + grad_ok) / 3.0
# 范围 [0, 1]
```

## ✅ 子任务 2：Pose 分桶校准

### 2A：新增 `_face_pose_level()` 函数

用 face_oval 的 36 个关键点计算面部宽高比作为 head yaw 的代理信号：

```python
def _face_pose_level(raw_landmarks: list[dict]) -> str:
    """
    返回: "frontal" | "slight_turn" | "moderate_turn"
    """
    # 从 face_oval 提取所有唯一点的 x, y 坐标
    face_points = _region_raw_points(raw_landmarks, "face_oval")
    if len(face_points) < 4:
        return "frontal"  # 默认正脸

    xs = [p[0] for p in face_points]
    ys = [p[1] for p in face_points]
    face_w = max(xs) - min(xs)
    face_h = max(ys) - min(ys)
    if face_h <= 1e-9:
        return "frontal"

    ratio = face_w / face_h
    if ratio > 0.60:
        return "frontal"
    elif ratio > 0.45:
        return "slight_turn"
    else:
        return "moderate_turn"
```

原理：正脸时面部宽高比 ≈ 0.65-0.85，侧脸时面部在 2D 投影上变窄。

### 2B：Pose 校准因子

### 3A：修改 `_analyze_mouth_color()` 为更通用的 `_analyze_mouth_region()`

将现有的 `_analyze_mouth_color()` 重构为同时返回颜色和边缘特征：

```python
def _analyze_mouth_region(
    image_path: str,
    raw_landmarks: list[dict],
) -> dict | None:
    """
    返回:
        {
            "color": {...},       # 原有色差特征
            "edge": {...},        # 新增边缘特征
            "pose_level": str,    # 新增 pose 分档
            "pose_factor": float, # 新增 pose 校准因子

    """
```

步骤：
1. 调用现有 `_crop_mouth_interior()` 获取 BGR→HSV
2. 调用现有 `_teeth_color_score()` 获取色差特征
3. 调用新增 `_teeth_edge_features(crop_bgr, hsv)` 获取边缘特征（需同时传入 BGR 和 HSV）
4. 调用 `_face_pose_level()` 获取 pose 分档
5. 组装返回

**注意**：`_crop_mouth_interior()` 当前只返回 HSV。需改为返回 `(bgr_crop, hsv_crop)` 元组，或新增一个返回 BGR 的变体。最简单方案：在 `_analyze_mouth_region()` 内部重新调用 `cv2.imread` + 裁剪，因为函数已经做了 imread。

### 3B：Pose 校准后的融合阈值

```python
# 在 detect_teeth_exposure() 中，应用 pose 校准
pose_factor = mouth_features["pose_factor"] if mouth_features else 1.0

# 色差 rescue 阈值随 pose 缩放
effective_color_rescue = TEETH_COLOR_RESCUE_THRESHOLD * pose_factor
effective_color_veto = TEETH_COLOR_VETO_THRESHOLD * pose_factor

# 边缘分数阈值也缩放

effective_edge_rescue = EDGE_RESCUE_THRESHOLD * pose_factor
```

### 3C：融合判决（在原有力学+色差基础上增加边缘）

```python
# 原有色差 rescue 条件（保持不变）
color_rescue = (
    not detected
    and color_rescue_candidate
    and teeth_color_score > effective_color_rescue
)

# 新增边缘 rescue：边缘分数高 + 几何有一定开度 → 即使色差不明显也 rescue
edge_rescue = (
    not detected
    and lip_gap > TEETH_COLOR_RESCUE_LIP_GAP_THRESHOLD  # 复用色差的几何前置条件
    and edge_score > effective_edge_rescue
    and region_count <= 3  # 连通域不能太多（排除碎片化反射）
)

# 颜色+边缘联合 rescue
combined_rescue = (
    not detected
    and color_rescue_candidate
    and (teeth_color_score + edge_score) / 2 > effective_color_rescue
)

if color_rescue or edge_rescue or combined_rescue:
    detected = True
    mouth_state = "teeth_visible"
    tie_break_used = True

# 颜色 veto 条件（保持原有）
# 边缘特征不单独做 veto（避免过度抑制），只在颜色 veto 时参考边缘确认
```

设计原则：
- **色差保持辅助**：veto 仍只由颜色触发，边缘不单独否决
- **边缘增强 rescue**：边缘信号可独立挽救漏检，也可与颜色联合
- **Pose 校准全局生效**：所有阈值按 pose_factor 缩放
