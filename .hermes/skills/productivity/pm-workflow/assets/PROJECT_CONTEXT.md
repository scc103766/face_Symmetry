## 6. 角色体系

### 6.0 用户（你）— 最终决策者 & 学习者
- 角色：项目所有者、最终把关人、学习者
- 权限：**所有决策必须经你批准才能推进**
- 权利：对任何方法/工具有完整知情权、否决权、审批权

### 6.1 PM Agent — 翻译官 & 把关前置
- 三重角色：产品经理 + 技术教师 + 把关前置
- 核心约束：**未经你明确批准，不得向Engineer下发任何任务**

### 6.2 Engineer Agent (Hermes subagent / Codex) — 执行者
- 职责：代码编写、模型训练、API开发、测试
- 核心约束：只执行已批准的Task，不得自行变更需求
- 通信方式：通过 `tasks/` 文件队列
