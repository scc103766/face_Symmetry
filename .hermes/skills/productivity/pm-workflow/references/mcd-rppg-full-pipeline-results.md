# MCD-rPPG 全量 Pipeline 结果与教训

> 2026-06-23：600 人 × 628 维面部特征全链路跑通，结论：当前数据不支持"扫脸看健康"。

## 全量扩展模式

从 16 人 balanced subset → 600 人全量的脚本适配模式：

1. **输入切换**：从 `sample_selection.csv`（split 文件）→ `mcd_rppg_gold.csv`（全量）
2. **ID 格式对齐**：全量 .npz 命名 `mcd_video_{patient_id}_{camera}_{step}_{view}.npz`
3. **元数据合并**：从 `mcd_rppg_gold.csv` 按 `_key` 列做 video-level join
4. **聚合键**：`patient_id`（不是 `subject_id`）
5. **输出隔离**：`features/mcd_rppg_full/` 和 `features/mcd_rppg_evm_full/` 独立于旧输出

## Phase 3 建模结果

### 金标准标签（HbA1c ≥ 6.5%，20 正 / 580 负）

```
E0 (年龄+BMI+性别)    AUC 0.849  ← 压倒性最强
E2 (面色)             AUC 0.817
E5 (面部全部)         AUC 0.715  ← 三个模态加起来反而不如纯面色
E6 (年龄+面部)        AUC 0.793  ← 加入面部后 AUC 从 0.849 降到 0.793
```

### Elevated-risk 标签（HbA1c ≥ 5.7%，198 正 / 402 负）

```
E0 (年龄+BMI+性别)    AUC 0.571  ← 中位年龄 20 岁，年龄不区分
E1 (临床档案)         AUC 0.605  ← 微弱最强
E2 (面色)             AUC 0.543
E5 (面部全部)         AUC 0.479  ← 低于随机
```

## 核心结论

1. **MCD-rPPG 不适合做 face-video-first 糖尿病风险评估**：正样本太少（20）且集中在高年龄段，年龄混杂压倒一切。
2. **E0 baseline（年龄+BMI+性别）是必须的**：不跑 E0 就无法判断面部特征是否有独立信号。
3. **面部特征加入 demographics 后反而拉低性能** → 说明当前面部信号是噪声，不是增量。
4. **elevated-risk 标签虽然正样本 10x（198），但年轻人群中 HbA1c 升高不体现在面部信号中**。
5. **技术栈全链路已跑通**（EVM → ROI → 特征 → 建模），但没有合适的 face+diabetes 金标准数据就无法验证核心假设。
